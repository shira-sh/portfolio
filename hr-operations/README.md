# מרכז תפעול משאבי אנוש (HR Operations Hub) - Prototype

פרוטוטייפ למערכת מרכזית לניהול עובדים, נוכחות, קליטה ומבנה ארגוני, המדגים כיצד ניתן
לאחד מידע המפוזר כיום בין מספר מערכות וקבצי Excel שונים בארגון.

ראו גם: [`ARCHITECTURE.md`](./ARCHITECTURE.md), [`ASSUMPTIONS.md`](./ASSUMPTIONS.md),
[`DISCOVERY_QUESTIONS.md`](./DISCOVERY_QUESTIONS.md).

## התקנה

```bash
npm install
```

## הרצה מקומית

```bash
npm run dev
```

האפליקציה תיפתח בכתובת שתוצג בטרמינל (בדרך כלל `http://localhost:5173`).

## חיבור קובץ נתונים (Excel)

המערכת אינה כוללת מסד נתונים - כל המידע נשמר בקובץ Excel מקומי בשם `HR_DEMO.xlsx`.

1. בהפעלה ראשונה תועברי אוטומטית למסך **הגדרות**.
2. אם אין ברשותך קובץ דמו - לחצי על "הורדת קובץ נתוני דמו" להורדת `HR_DEMO.xlsx` (קובץ דמו מוכן
   נמצא גם בנתיב `public/seed/HR_DEMO.xlsx` בקוד המקור, ובנתיב `seed-data/HR_DEMO.xlsx`).
3. לחצי על "בחירת קובץ נתונים" ובחרי את הקובץ.
   - בדפדפנים מבוססי Chromium (Chrome, Edge) תיפתח בחירת קובץ עם אפשרות שמירה ישירה חזרה לקובץ.
   - בדפדפנים אחרים (Firefox, Safari) הקובץ ייטען לקריאה/כתיבה בזיכרון, ושינויים יישמרו רק על ידי
     "ייצוא" והחלפת הקובץ המקומי ידנית.

## יצירת קובץ נתוני דמו מחדש (Seed)

```bash
npm run seed
```

הפקודה יוצרת קובץ `seed-data/HR_DEMO.xlsx` חדש עם כ-170 עובדים, 8 מחלקות, 16 יחידות, נוכחות לחודש
מלא, חריגים, תהליכי קליטה ומשתמשי דמו לכל תפקיד. יש להעתיק אותו ידנית ל-`public/seed/HR_DEMO.xlsx`
אם רוצים שהוא יהיה זמין להורדה מתוך האפליקציה עצמה.

## כניסה למערכת (Demo Login)

אין הזדהות אמיתית. במסך ההתחברות ניתן לבחור אחד ממשתמשי הדמו הקיימים בקובץ (לפי הרשאה):
עובד/ת, מנהל/ת, רכז/ת משאבי אנוש, שכר, מנהל/ת משאבי אנוש, מנהל/ת מערכת.

## שמירת שינויים / ייצוא

- **שמירה** (רק בדפדפנים עם הרשאת כתיבה ישירה): כל פעולה שמשנה נתונים (הוספת עובד, אישור קליטה,
  דיווח נוכחות וכו') נשמרת אוטומטית לקובץ המקומי המחובר.
- **ייצוא**: במסך "ייבוא וייצוא" או "הגדרות" ניתן לייצא בכל שלב קובץ Excel מעודכן.
- **החלפת קובץ**: מאפשר להתנתק ולהתחבר לקובץ אחר.

## בדיקות שבוצעו

- `npm run build` - בנייה מלאה (TypeScript strict + Vite) עוברת ללא שגיאות.
- זרימת דמו מלאה נבדקה בדפדפן Chromium אמיתי (חיבור קובץ, התחברות בתפקידים שונים, דשבורד,
  רשימת עובדים, פרופיל עובד/ת, אישור קליטה, דיווח כניסה/יציאה לנוכחות) - ראו את תיאור התרחיש
  המלא בסעיף "תרחיש דמו מרכזי" ב-`ARCHITECTURE.md`.

## טכנולוגיות

React, TypeScript (strict), Tailwind CSS, React Router, Zustand, React Hook Form + Zod,
SheetJS (xlsx), Lucide Icons. ללא שרת, ללא מסד נתונים, ללא הזדהות אמיתית - ראו `ARCHITECTURE.md`
לפירוט המלא.
